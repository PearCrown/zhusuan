# 第7组：受限维护台

入口为 `/maintenance/`，在账号中心以维护人员身份登录后可见链接。学生、教师、仅有staff/superuser标志者不能因此进入；服务端需要maintainer组及维护账号、维护班级两项操作权限。网页不提供维护人员任命、密码修改、任意权限编辑或账号删除。

## 第一次准备维护人员

1. 在本地网页注册一个专用于维护的普通账号，自行保存密码。
2. 由拥有可信终端和数据库访问权限的项目负责人执行，替换下面的用户名：

```powershell
.\.venv\Scripts\python.exe -X utf8 manage.py migrate --noinput
.\.venv\Scripts\python.exe -X utf8 manage.py init_roles
.\.venv\Scripts\python.exe -X utf8 manage.py provision_maintainer your_username
```

3. 此账号旧会话已失效，重新登录账号中心，点击“进入维护台”。不会设置staff/superuser，也不自动获得教师成绩访问权限。没有内置维护账号或共享密码。

撤销维护身份由可信终端执行 `manage.py provision_maintainer your_username --revoke`。命令拒绝撤销最后一个启用的维护人员；此约束只适用于该命令，数据库管理员仍能直接修改数据。网页不允许修改自己或任何维护员、staff、superuser账号，减少误锁与提权路径。

## 操作流程

- **创建/修改班级**：设置编号、名称、启用状态。不能删班清空数据，停用后教师下一次请求不能访问。
- **账号状态和教师身份**：从账号行进入，默认带入当前账号、版本及选项；可以停用/启用、授予/撤销教师角色。撤销教师身份同时清理其教师班级授权，防止日后重新授予身份时意外恢复旧授权。
- **学生归属**：从账号行进入，选择班级，留空代表取消归属。教师也可作为玩家在班。不能把停用账号分配进班级，不能向停用班级新增归属。
- **教师授权**：选择班级，勾选代表授予，不勾选代表撤销。新增需要启用的教师和启用的班级；停用班级仍允许撤销旧授权。
- 保存前须勾选核对确认。版本号表示记录是否变化，旧页面不能覆盖新变更；遇到冲突应回到维护首页，从账号/班级行重新进入。切换表单目标后必须核对该目标的版本和值。

## 安全与审计

使用现有Django会话和CSRF，不另造管理员密码系统。每次操作在事务中锁定并重新检查操作者及目标；变更与MaintenanceEvent同事务，写日志失败则变更回滚。拒绝额外字段、重复字段、特权目标及没有核对确认的请求。

审计包含时间、操作者、操作类型、目标和前后白名单字段，不记录密码、密钥、验证码或原始请求。网页不提供日志修改/删除；这不是数据库层不可篡改日志，拥有数据库权限者仍能改变它。

对账号的角色、启用状态、归属和授权操作会递增session_revision，使所有旧会话的框架认证摘要永久失效。停用后又启用也不会恢复旧登录，包括停用期间从未访问的设备。旧会话记录可能留在会话表至过期清理，但令牌已不能通过身份校验；下次访问才让对应设备看到退出提示。维护人员自己不受目标账号操作影响。

revision为0时保留原有框架摘要，所以添加此字段本身不强制登出已有普通用户。仍依赖Django密码摘要、密钥及回退密钥机制；未更换会话存储。直接SQL、旧的手工shell授权和QuerySet.update不会自动获得这套维护审计/撤销保证，后续入口必须复用受控服务。

页面no-store，并在离开/隐藏时用JavaScript清空内容，返回时重新请求服务器验证权限；未提交内容会丢弃。禁用JavaScript时基本表单仍能提交，但没有这层页面隐藏清理能力。服务器仍对每次操作独立验证。

## 当前使用边界

账号列表每页30个；班级摘要最多100项，操作下拉框包含全部候选记录；审计仅展示最近50条。适用于当前小范围教学试用，不是大型学校的完整搜索、审计查询或批量导入系统。没有历史转班报表、密码恢复、验证码、生产部署及100人容量结论。
