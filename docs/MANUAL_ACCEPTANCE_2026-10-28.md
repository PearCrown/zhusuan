# 本地网页人工验收记录

日期：2026-10-28。范围：账号、基础权限、游戏接入样例、教师工作区及日常维护。

评测方式：用户在本机内置浏览器中逐步操作，助手提供操作步骤，用户在对话中逐项反馈结果。下列“通过”依据用户实际操作后的确认，未由助手重新执行每一项，也不是自动化测试的新计数。浏览器具体内核和版本未单独记录，不外推为其他浏览器的兼容性结论。

版本背景：验收期间发现重置入口不清楚，随后以738f215修复，并同步至远程479cfcf（含发布记录）。修复后的新入口和人工恢复流程已由用户重新操作确认。其他通过项是在本次连续评测过程中确认，不宣称全部由同一提交重新跑过。

## 评测准备与权限边界

使用用户自行注册的专用评测学生、教师及维护账号，密码均由用户保管。最初的班级归属、教师授权及维护身份由助手通过可信终端准备，不能据此声称普通用户能在网页获得维护权限。后续班级维护、教师授权增撤、学生归属及账号启停由用户通过维护网页完成。

本记录不收录密码、恢复凭据、会话Cookie、数据库UUID或真实师生资料。评测账号与数据保留在本机数据库，不随代码上传；没有执行清库或自动删除评测账号。

## 发现的问题及处理

1. **重置密码入口难找，已修复并复测。** 原生成成功页只有地址文字，用户需要退出后从登录表单进入。现成功页明确显示“打开重置密码页面”，提醒先复制凭据；链接不携带秘密，生成成功后不再重复显示生成表单或无关菜单。导航整理的自动化与隔离浏览器证据见NAVIGATION.md；本次用户另外走通完整人工恢复。
2. **名单与成绩导出曾被混淆，澄清后通过。** 两个按钮输出不同文件，名单本来不含成绩。用户重新选择成绩CSV后确认符合。未将此情况判定为成绩丢失或导出失败，也未凭后端接口有数据就提前认定实际下载通过。
3. **班级编号缺少填写提示，待体验改进。** 当前规则为首尾空白去除后1—32个可见字符、全局唯一、禁止控制字符、区分大小写。建议格式只是维护约定，并未限制为仅字母数字。此处尚未新增网页提示，也未改变校验规则。
4. **单独关闭学生角色暂不处理。** 用户了解角色、班级归属与整账号停用的区别后，明确暂不调整。属于暂缓的功能讨论，不记为本轮缺陷或已实现能力。
